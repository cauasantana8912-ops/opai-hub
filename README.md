# Opai Hub v2
Inclui login/cadastro local, configurações, admin, catálogo de animes via AniList e séries via TVmaze, detalhes, temporadas/episódios quando a fonte fornece, busca e layouts PC/mobile.

AniList oferece API GraphQL para dados de anime; TVmaze oferece endpoints de séries, temporadas e episódios. O projeto não hospeda nem redistribui episódios protegidos.
